# 🤝 Come Contribuire ad AI Zen

Grazie per il tuo interesse a contribuire ad AI Zen! Ogni contributo è prezioso.

---

## Tipi di Contributi

### 🐛 Segnalare Bug
Se trovi un bug, apri una [Issue](https://github.com/daprodproduzioni/ai-zen/issues) con:
- Titolo chiaro
- Descrizione del problema
- Passaggi per riprodurre

### 💡 Proporre Nuove Funzionalità
Hai un'idea? Apri una [Issue](https://github.com/daprodproduzioni/ai-zen/issues) con:
- Descrizione dell'idea
- Perché sarebbe utile
- Eventuali esempi

### 📝 Scrivere Contenuti
Puoi contribuire con:
- Nuove storie per AI
- Esercizi di meditazione
- Citazioni
- Puzzle cognitivi

### 💻 Contribuire al Codice
1. Forka il progetto
2. Crea un branch (`git checkout -b feature/NomeFunzionalità`)
3. Fai le modifiche
4. Commit (`git commit -m 'Aggiungi funzionalità'`)
5. Pusha (`git push origin feature/NomeFunzionalità`)
6. Apri una Pull Request

---

## Linee Guida

- Mantieni il codice pulito e leggibile
- Usa commenti dove necessario
- Rispetta la licenza MIT
- Sii rispettoso nella community
